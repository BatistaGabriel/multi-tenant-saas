# vetta-zinda

## Pré-requisitos

Antes de qualquer coisa, garanta que estas ferramentas estão instaladas na máquina:

- nvm
- SDKMAN!

## Configuração do ambiente

Este projeto usa arquivos de versão por diretório:

- `.nvmrc` para Node.js
- `.sdkmanrc` para Java (JDK)

Ao entrar na pasta do projeto, execute:

```bash
nvm use
sdk env
```

## Verificação rápida

Confirme se as versões foram aplicadas:

```bash
node -v
npm -v
java -version
```
